Consulting and engineering for data systems.

The work behind our products, done for clients.

  • Data platforms and analytics engineering

    We design semantic models, define metrics as code, and build the dashboards and pipelines on top. LeapView is this work as an open-source product.

    See LeapView

  • CAD extraction and engineering master data

    We read CAD files and vault databases without changing them and match them to the ERP item master with a pipeline built for the engagement. Alloy Catalog is the product built from this work.

    See Alloy Catalog

  • AI agents with governed access

    We build assistants and MCP endpoints that answer from your data with each person’s own permissions and cite their sources. LeapView’s agent tools follow its access rules; Alloy Catalog’s assistant cites every document it names.

    See LeapView’s AI tools

  • Product engineering

    We take software from first version to a product other teams run, in Go, Rust and TypeScript on DuckDB and PostgreSQL. We built LeapView and Alloy Catalog this way.
