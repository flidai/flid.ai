Design system

The tokens and components that build flid.ai. Every page uses one stylesheet, /assets/site.css, and nothing on this page is used elsewhere.

Colour

The functional subset of Primer 11.9.0, as in the brand assets. Light is the default; dark follows the reader's system setting. Blue is reserved for links, focus and the one primary action on a page.

Light

  • --bgColor-default #ffffff, page
  • --bgColor-muted #f6f8fa, footer
  • --fgColor-default #1f2328, text
  • --fgColor-muted #59636e, secondary text
  • --borderColor-default #d1d9e0, rules
  • --fgColor-accent #0969da, links, focus, primary button

Dark

  • --bgColor-default #0d1117, page
  • --bgColor-muted #151b23, footer
  • --fgColor-default #f0f6fc, text
  • --fgColor-muted #9198a1, secondary text
  • --borderColor-default #3d444d, rules
  • --fgColor-accent #4493f8, links; #1f6feb, focus and primary button

Type

Geist, the typeface in the lockup, at two weights: 400 for text, 600 for headings and buttons. Five sizes. Sentence case everywhere.

Buttons and links

One primary button per page, for the main next step. Secondary buttons for the rest. Links in text are blue and underlined.
