Alloy Catalog

Engineering master data from your CAD files and ERP. One page per part number, and an assistant that cites the files and records it used.

Available as a pilot.

Write to hello@flid.ai about a pilot Visit alloycatalog.com

What it does

Read-only sources
Reads a Vault’s SQL database, set up for each deployment, or Inventor files (.ipt, .iam, .idw, .ipn) on a file share. It does not change them.
ERP matching
Files are matched to the ERP item master and transactions through a pipeline set up for each company.
One page per part
Key facts with their sources, previews, a 3D view where a STEP or DWF file exists, bill of materials, where-used, drawings with title blocks and parts lists, ERP items and stock, classification, people and history.
Search
One search box with facets and columns, and quick search with ⌘K.
Data quality
An overview score, ERP consistency checks, and lists of conflicts between CAD and ERP.
Assistant
Answers questions about parts and assemblies and cites every document it names. A read-only MCP endpoint gives other AI clients the same access.

Pilot

A four-week pilot on your own data, with a fixed scope and a fixed price, credited when you subscribe. Details are on alloycatalog.com.
