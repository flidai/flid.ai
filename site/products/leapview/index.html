LeapView

Open-source business intelligence. Define each metric once in code, then use it in dashboards, queries and AI tools.

Open source, Apache-2.0. Alpha, v0.4.0-alpha.1, for controlled evaluation.

Read the documentation View the code on GitHub

What it does

Analytics in Git
Connections, transformations, semantic models, refresh pipelines and dashboards are YAML files in Git. LeapView validates the whole resource graph before it publishes.
One definition per metric
A metric defined once is used by every dashboard, headless query and AI tool.
26 visual types
Charts, maps, KPI cards, tables, matrices and pivots. A browser builder drafts and previews dashboards and exports YAML.
Access control
Roles, resource grants, row filters and column masks apply in the query layer. Sign-in with OIDC; user provisioning with SCIM.
AI tools
An optional built-in assistant, and an OAuth-protected MCP endpoint for external AI clients.
Self-hosted
Go, DuckDB, DuckLake and PostgreSQL on your infrastructure. Command-line tools for Linux and macOS.

A metric in code

Revenue, defined once in a semantic model. Dashboards, queries and AI tools refer to it by name.

- name: revenue
  type: simple
  empty: zero
  label: Revenue
  format: currency
  agg: sum
  field: amount
